# Save image as PNG / 画像をPNGで保存

Chrome で画像を右クリックし、PNG に変換して保存する自分用拡張です。

## できること
- 画像の右クリック時だけ「PNGとして保存」を表示
- PNG に変換して保存
- 2つの保存モードをポップアップから切り替え
- 設定を `chrome.storage.local` に保持
- 同名ファイルは Chrome の `uniquify` で自動連番化

## 使い方
1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を有効化する
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. このフォルダを選ぶ

## 保存モード
- ダウンロードフォルダに即保存
- 保存先を選ぶ

## 補足
- 外部サービス連携や解析は入れていません
- 任意サイト上の画像 URL を取得するため、`<all_urls>` の host permission を使っています
- `blob:` URL や CSS 背景画像など、要件書で許容された特殊ケースは MVP 対象外です
